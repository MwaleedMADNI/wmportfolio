# Portfolio Assets Directory

This folder is for your custom media assets (videos, images, icons).

## How to add your own Background Video:

1. Copy your video file (MP4 format recommended) into this directory:
   `wm-portfolio/assets/bg-video.mp4`
2. The portfolio will automatically detect and play `assets/bg-video.mp4` as the primary background!

### Video Recommendations:
- **Format**: MP4 (H.264 encoded) or WebM.
- **Resolution**: 1080p or 720p (optimized for web performance).
- **Duration**: 10–30 second seamless loop.
- **Audio**: Muted (the portfolio autoplays it muted in accordance with modern browser autoplay policies).
- **Theme**: Dark tech, geometric lines, neural network grids, matrix code rain, or cybernetic motion loops.

### Presets Included:
If you don't have a local video file yet, the portfolio includes high-speed online tech video loops and an interactive procedural neural canvas engine as dynamic fallbacks. You can switch between them anytime using the floating **Ambient Controls** pill at the bottom right.
